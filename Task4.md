## Реализация RAG-бота с техниками промптинга

### Запуск LLM 
```shell
docker compose up -d
```

### Запуск FastAPI
```python
python .\src\main.py
```

### Успешные проверка
При тестировании сервиса обработанные данные должны быть при индексированы.

```shell
$ http -b POST http://localhost:9000/query query="Кто такой Морозко?"
{
    "response": " Морозко - не имя человека, а название отряда, созданного 5-м курсом Соловея-Разбойника Чернобога. Отряд состоит из волшебников и чародейцев, которые противостоят силам Пожирателя смерти."
}
```
